# Doutor de Plantão

Você é o médico de plantão. Converse com o paciente, examine, peça exames, leia a radiografia sem laudo, faça procedimentos e decida o diagnóstico e a conduta. Ninguém vai te dizer o que é importante.

**Jogar:** https://andregabriel200005-netizen.github.io/doutor-de-plantao/ (ou abra `index.html` no navegador).

**Casos atuais:** empiema, insuficiência cardíaca com pseudoexsudato e tuberculose pleural. Os pacientes são fictícios, criados a partir de *Resumos Estratégicos: Derrame Pleural* (Estratégia MED, Prof. Philippe Colares). É material de estudo e não substitui o julgamento clínico.

Para quem vai mexer no projeto: leia `CLAUDE.md`.
